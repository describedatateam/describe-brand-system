geometry that generates it, the typographic system, and the written rules that

Plex Mono are all SIL Open Font Licence 1.1 at the time of writing. Verify
before any commercial redistribution.

**Public data** used in worked examples (UCI Machine Learning Repository,
Online Retail) is cited where it appears and is not redistributed here.

If the generative code in `geometry/` is ever to be released separately — it
is a general astrolabe-geometry library and would stand on its own — split it
into its own repository under an explicit open-source licence. Do not add a
permissive licence to this repository, which would cover the identity itself.
