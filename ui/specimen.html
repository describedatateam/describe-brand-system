00

The colour law

UI is where it is most tempting to break it — a coral error message looks right and means the wrong thing.

Blue is live Active, selected, in progress, the one primary action.
Coral is an outlier In data, and nowhere else. Never an error, a warning or an accent.
Red is negative A value that went down in a bad way, or an action that failed.
Green is positive A value that moved in a good way, or an action that completed.
01

Buttons

Not pills. A label and a direction. The one action that matters gets calibration ticks either side — and there is only ever one per view.

Primary · default · secondary · quiet · danger

Small · disabled · busy

The technical feel comes from the ticks and the mark, not the typeface. Your brief shows buttons as [ RUN ANALYSIS → ], which reads as mono — but you've since ruled mono out of anything that isn't numerals or tiny labels, and your later direction wins. Labels are Readex Pro, uppercase and tracked in English; in Arabic there is no case and no tracking, so weight carries it. Tab to any button to see focus: a sighting frame, not a glow. Busy replaces the arrow with a tally that counts while the work runs.

Referral's revenue is circled, not removed — the marker sits on the value, because the value is what's anomalous, not the channel. One order of about 34,000 USD carries most of that channel — so the +212% is real and misleading at once. The marker says look here; deleting the row would hide exactly the thing worth a conversation. Direct has no August baseline, so its change is shown as a null, not as zero — "we don't know" and "nothing happened" are different findings. Negatives use a true minus sign (−), not a hyphen.

Toasts →

Warning has no colour of its own, on purpose. Your palette has none to give it — and coral would be the obvious grab and exactly the wrong one, since coral means a data outlier. So a warning is told apart by form: its icon is a pointer arriving at a limit, and its edge rule is heavier. If you'd rather it had a colour, that is a decision to add one to the palette deliberately — see the open questions.

Colour follows meaning, not the sign. Return rate fell by 0.6 points — a negative number and a good outcome — so it is green. A kit that colours by sign would have painted it red. A figure read as a statement is serif (the readouts, in Fraunces); a figure read as one measurement in a set is mono (the table). The delta and the count are measurements, so they're mono.
